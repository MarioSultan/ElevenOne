# ElevenOne

![ElevenOne
Logo](https://raw.githubusercontent.com/MarioSultan/ElevenOne/main/banner.png)

**ElevenOne** is an open-source Python library designed to provide a
unified environment for scientific computing and working with physical
quantities. It aims to make the manipulation of physical magnitudes,
units, measurements, and numerical data intuitive and accessible, while
preserving the mathematical consistency behind physical calculations.
ElevenOne seeks to bridge the gap between numerical computation and
physical interpretation, allowing users to work naturally with
quantities, perform unit-aware operations, organize scientific data, and
visualize results. Its main goal is to provide a practical and coherent
framework for scientific programming in Python, whether for education,
experimentation, numerical analysis, or physical applications.

------------------------------------------------------------------------

## Installation

To install ElevenOne from PyPI, write in the terminal:

``` bash
pip install elevenone
```

------------------------------------------------------------------------

## Getting started

ElevenOne is designed to make scientific calculations straightforward
while keeping track of the physical meaning of the quantities involved.

Once installed, import the library using:

``` python
import elevenone as eo
```

You can then start working with physical quantities, units, scientific
data, and the tools provided by the library.
