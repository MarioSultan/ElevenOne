# Scientific Reports (`Data.generate_report`)

The reporting engine is a cornerstone of **ElevenOne**. The library gets its name—**ElevenOne**—from the **eleven fixed, structured sections** automatically generated in every scientific report.

With a single method call, ElevenOne transforms any dataset into an interactive **HTML** document or a standalone, publication-ready **PDF** report without requiring external tools like `wkhtmltopdf` or `WeasyPrint`.

> 💡 **Sample Report:** You can preview an example of an interactive report generated by ElevenOne here: [View Sample HTML Report](https://raw.githubusercontent.com/MarioSultan/ElevenOne/main/imgs/test_report.html)

---

## The 11 Sections of ElevenOne

Every report produced by `generate_report()` contains exactly eleven numbered analytical sections:

 1. **Executive Dataset Overview:** Summary of row counts, total columns, and numeric vs. non-numeric variables.

 2. **Primary Descriptive Statistics:** Standard statistical metrics (Count, Mean, Standard Deviation, Min, Q1, Median, Q3, Max) with automatic unit formatting.

 3. **Advanced Statistical Indicators:** High-order statistical indicators including Variance, Interquartile Range (IQR), Skewness, and Excess Kurtosis.

 4. **Pearson Correlation Matrix:** Tabular correlation coefficients between all numerical variables.

 5. **Univariate Distribution Analysis:** Individual frequency distribution histograms for each numerical variable.

 6. **Global Quartile & Outlier Analysis:** Comparative box-and-whisker plots highlighting medians, IQRs, and outliers.

 7. **Distribution Density Analysis:** Comparative violin plots detailing continuous kernel density shapes.

 8. **Bivariate Relationships & Linear Regression:** Fitted scatter plots with $1\sigma$ error bars and linear regression trendlines for all variable pairs.

 9. **Regression Residual Analysis:** Residual plots ($y - \hat{y}$) for verifying linear fit assumptions and identifying systematic deviations.

10. **Multivariate Pairwise Analysis:** A full $n \times n$ matrix combining univariate diagonal histograms and off-diagonal scatter plots.

11. **Correlation Heatmap:** Color-coded Pearson correlation matrix heatmap with annotated coefficients.

## Basic Usage

Generating a report requires only a single line of code on any `Data` object:

```python
import elevenone as eo

# Load dataset
data = eo.load_data("experiment_data.csv")

# Generate interactive HTML report
data.generate_report("experiment_report.html", format_type="html")

# Generate standalone PDF report
data.generate_report("experiment_report.pdf", format_type="pdf")
```

---

## Output Formats: HTML vs. PDF

### Interactive HTML (`format_type="html"`)

* Fully self-contained single file with embedded CSS styling and base64-encoded plot images.
* Features collapsible `<details>` sections for easy navigation through the 11 sections.
* Fully responsive across desktop, tablet, and mobile browsers.

### Standalone PDF (`format_type="pdf"`)

* Built directly using [ReportLab](https://www.reportlab.com/) (requires `pip install reportlab`).
* Standardized A4 multi-page layout with clean headers, footers, pagination, and high-resolution vector plots.
* No external PDF conversion dependencies needed.

## Customizing Title, Author, and Branding

You can customize report metadata and header branding (such as embedding a custom institution or company logo):

```python
data.generate_report(
    output_path="custom_report.html",
    format_type="html",
    title="Pendulum Oscillation Lab Analysis",
    author="Physics Dept. - Group 4",
    logo_path="https://myuniversity.edu/assets/logo.png"  # Local path or URL
)
```

## Function Reference

```python
Data.generate_report(
    output_path: str,
    format_type: str = "html",
    title: str = "Comprehensive Scientific Data Report",
    author: str = "ElevenOne",
    logo_path: str = DEFAULT_LOGO_URL
)
```

### Parameters

| Parameter | Type | Default | Description | 
| :--- | :--- | :--- | :--- | 
| `output_path` | `str` | *required* | Output file path (e.g., `"report.html"` or `"report.pdf"`). | 
| `format_type` | `str` | `"html"` | Export format (`"html"` or `"pdf"`). | 
| `title` | `str` | `"Comprehensive Scientific Data Report"` | Main header title of the document. | 
| `author` | `str` | `"ElevenOne"` | Author name or organization displayed in the report header. | 
| `logo_path` | `str` | GitHub Banner URL | Path (or URL) to a logo image displayed in the header. |
